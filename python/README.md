# memtrails for Python

A native Python port of [memtrails](https://github.com/cmaftuleac/memtrails): retrieval and exploration for any text —
e-mail, chat, notes, memos, documents, news, commit messages, conversations. Everything you add is searchable the moment
it is added, on your own machine, with no server and no language model. Give it a language model too, and it
consolidates what it holds into typed knowledge, dated events and profiles.

This package is a port of the TypeScript library (npm `memtrails` 0.4.0), not a wrapper around it: the same
algorithms, constants, prompts and files, in Python.

## Install

```bash
pip install memtrails
```

Python 3.10 or newer, on macOS or Linux (x64 or arm64).
